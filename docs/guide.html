Quick Start / 快速开始

English

Activate the virtual environment, run checks, then start the mock meeting first.

cd /Users/yuanxiaoyu/projects/LocalMeetingCopilot
source .venv/bin/activate
python run.py --check
python run.py --model-check --profile de
python run.py --mock

Use mock mode first to verify the UI, Ollama, profile settings, and translation pipeline without touching audio devices.

中文

先激活虚拟环境，运行自检，再启动 mock 会议。

cd /Users/yuanxiaoyu/projects/LocalMeetingCopilot
source .venv/bin/activate
python run.py --check
python run.py --model-check --profile de
python run.py --mock

建议先用 mock 模式确认 UI、Ollama、语言频道和翻译队列都正常，再开始调真实音频设备。

Model Preflight / 模型预检

English

Before a real meeting, verify the local ASR cache and Ollama model without downloading anything automatically.

python run.py --model-check --profile de --preset fast --style meeting

If a model is missing, the command exits non-zero and prints the exact fix command, such as ollama pull qwen2.5:3b-instruct.

中文

真实会议前先检查本地 ASR 缓存和 Ollama 模型；这个命令不会自动下载任何东西。

python run.py --model-check --profile de --preset fast --style meeting

如果模型缺失，命令会返回非 0，并打印明确修复命令，例如 ollama pull qwen2.5:3b-instruct。

Diagnostics Bundle / 诊断包

English

When a Windows or macOS machine behaves differently, generate a shareable diagnostics bundle.

python run.py --doctor --profile de --preset fast --style meeting

The folder is written under logs/diagnostics/diagnostic_YYYYMMDD_HHMMSS/. It includes system, config, audio device, Ollama, model preflight, Git, and Python package metadata, but no audio recording or transcript contents.

中文

如果 Windows 或 macOS 机器表现和你本机不一样，可以生成一个可分享的诊断包。

python run.py --doctor --profile de --preset fast --style meeting

文件夹会写入 logs/diagnostics/diagnostic_YYYYMMDD_HHMMSS/，里面包含系统、配置、音频设备、Ollama、模型预检、Git 和 Python package 元信息，但不会录音，也不会读取逐字稿内容。

Support Bundle / 支持包

English

For remote debugging, generate one zipped bundle with environment check, model preflight, and doctor output.

python run.py --support-bundle --profile de --preset fast --style meeting

The zip is written to logs/support/support_YYYYMMDD_HHMMSS.zip. It does not listen to the microphone unless audio test is explicitly included.

python run.py --support-bundle --profile de --support-include-audio-test --audio-test-seconds 8
中文

远程排查时，用一个命令生成 zip，里面包含环境自检、模型预检和 doctor 输出。

python run.py --support-bundle --profile de --preset fast --style meeting

zip 会写到 logs/support/support_YYYYMMDD_HHMMSS.zip。默认不会监听麦克风；只有显式开启 audio test 时才会做音频/VAD 校准。

python run.py --support-bundle --profile de --support-include-audio-test --audio-test-seconds 8

Audio Test And Crash Logs / 音频测试与闪退日志

English

Run a short calibration before a real meeting to verify that the selected devices are producing audio and triggering VAD cuts.

python run.py --audio-test --profile de --audio-test-seconds 12

The test does not start Whisper or Ollama. It prints live RMS, peak level, VAD state, chunk count, speech starts, and completed cuts. Add --no-mic-track or --no-remote-track to isolate one side.

Unexpected exits are written to logs/crash/crash_YYYYMMDD_HHMMSS_xxxxxx.txt with platform details and traceback.

中文

真实会议前可以先跑一个短校准，确认当前选择的设备真的有声音，并且能触发 VAD 切句。

python run.py --audio-test --profile de --audio-test-seconds 12

这个测试不会启动 Whisper 或 Ollama，只会输出实时 RMS、peak、VAD 状态、chunk 数、speech start 和完成切句次数。加上 --no-mic-track 或 --no-remote-track 可以单独排查一边。

如果程序意外退出，闪退报告会写入 logs/crash/crash_YYYYMMDD_HHMMSS_xxxxxx.txt，里面包含系统信息和 traceback。

macOS Guide / macOS 使用

English

For local microphone only:

python run.py --mic

For two-track experiments, use a local mic plus a remote input device such as Microsoft Teams Audio, Zoom Audio, BlackHole, or Background Music.

export LMC_MIC_DEVICE_INDEX=0
export LMC_REMOTE_DEVICE_INDEX=2
python run.py --mac-live --profile de --preset fast --style meeting

If no remote input appears, install BlackHole and route meeting audio into it.

brew install blackhole-2ch
中文

只测试本地麦克风：

python run.py --mic

双轨实验模式使用本地麦克风加远端输入设备，例如 Microsoft Teams Audio、Zoom Audio、BlackHole 或 Background Music。

export LMC_MIC_DEVICE_INDEX=0
export LMC_REMOTE_DEVICE_INDEX=2
python run.py --mac-live --profile de --preset fast --style meeting

如果没有远端输入设备，可以安装 BlackHole，并在 Audio MIDI Setup 中把会议声音路由进去。

brew install blackhole-2ch

Dashboard Controls / 控制面板

English
  • Profile: German, English, or German + English.
  • Preset: fast, balanced, or accurate.
  • Tune: quick fast / balanced / accurate buttons for live latency comparison.
  • Style: literal, meeting-note, or natural Chinese.
  • Choose mic and remote input devices before pressing Start.
  • Toggle mic/remote tracks, report saving, privacy mode, and debug WAV.
  • Enable auto summary on End and tune VAD Sensitivity for faster or safer cuts.
  • Latency shows ASR, LLM, and total time per translated sentence.
  • Audio meters show live Mic/Remote RMS level and VAD speech/idle state.
  • Performance shows the latest final subtitle timeline; JSONL records are written to logs/performance/ when privacy mode is off.
  • Latency Window shows rolling ASR, LLM, queue, and total avg/p95/max with target bars for the current tuning window.
  • Select a transcript row to rename Remote Participant; the alias is remembered for future speech.
  • Runtime choices are saved to local settings.json and restored on the next launch.
中文
  • Profile：德语、英语、德英混合。
  • Preset：fast、balanced、accurate。
  • Tune：快速切换 fast / balanced / accurate，方便实时比较延迟。
  • Style：精准直译、会议纪要风、自然中文。
  • 建议点击 Start 前先选好麦克风和远端输入设备。
  • 可以开关本地/远端轨道、报告保存、隐私模式和 debug WAV。
  • 可以开启 End 后自动总结，并用 VAD Sensitivity 调整断句灵敏度。
  • 延迟诊断会显示每句话的 ASR、LLM 和总耗时。
  • Audio meters 会显示 Mic/Remote 的实时 RMS 音量和 VAD speech/idle 状态。
  • Performance 会显示最新完整字幕的时间线；隐私模式关闭时，JSONL 会写到 logs/performance/。
  • Latency Window 会显示当前调参窗口内 ASR、LLM、queue、total 的平均、p95、最大值和目标进度条。
  • 选中逐字稿后可以把 Remote Participant 改成真实姓名，后续会自动记住。
  • 运行时选择会保存到本地 settings.json，下次启动自动恢复。

Profiles And Vocabulary / 语言频道与词库

English

Use --profile de for mostly German meetings. It forces German ASR, injects German business vocabulary, and reduces multilingual hallucinations.

python run.py --mac-live --profile de --preset fast --style meeting

Partial subtitles show temporary ASR text while someone is speaking. Final subtitles are translated after the sentence is cut and refined. Chinese translation streams into the overlay while Ollama is still generating.

When the meeting ends, the dashboard shows an instant local summary preview first, then replaces it with the Ollama-refined summary. German clause fragments around weil, dass, wenn, and obwohl are held briefly for cleaner translations.

Add names, company terms, project names, and acronyms to profiles/custom_terms.txt. Use profiles/terms.yaml for precise translation terms with variants, Chinese targets, categories, and priorities. Only matched top terms are injected into each translation prompt.

- source: Kundentabelle
  variants: ["Kunden Tabelle", "customer table"]
  zh: 客户表
  category: data
  priority: high

Use helper commands to search, add, or import glossary terms without hand-editing YAML.

python run.py --glossary-search "Bitte pruefen Sie die Kunden Tabelle." --profile de
python run.py --glossary-add "Kundentabelle" --glossary-zh "客户表" --glossary-variants "Kunden Tabelle,customer table" --glossary-category data --glossary-priority high --glossary-profiles de,de-en
python run.py --glossary-import /absolute/path/to/terms.csv

CSV imports accept source, zh or target_zh, variants, category, priority, and profiles. Existing sources are updated in place.

Optional Silero VAD is used automatically when installed; otherwise the built-in energy VAD remains active.

python -m pip install -r requirements-vad.txt
export LMC_VAD_MODE=auto

For lower first-sentence latency, keep LMC_WARMUP=1. To protect final subtitles from CPU contention, keep LMC_PARTIAL_SKIP_WHEN_ASR_BUSY=1. Common fillers are translated locally, short sentences use smaller Ollama output limits, repeated final translations use cache, and LMC_SHUTDOWN_WAIT_MS bounds how long exit waits for background work.

Disk translation cache is stored at logs/cache/translation_cache.jsonl only when privacy mode is off. Performance timeline JSONL is stored at logs/performance/ only when privacy mode is off, and records timing metadata instead of transcript text.

If Ollama requests hang or app shutdown feels too slow, set LMC_OLLAMA_TIMEOUT_SECONDS=20.

中文

德语会议优先使用 --profile de。它会强制德语 ASR，注入德语业务词表，并减少多语言幻听。

python run.py --mac-live --profile de --preset fast --style meeting

说话中会先显示 partial 临时字幕，完整句切好后再进入精修翻译。Ollama 生成中文时会流式更新到悬浮窗。

会议结束后，Dashboard 会先显示本地规则 summary，再用 Ollama 精修版替换。遇到 weil、dass、wenn、obwohl 等德语从句片段时，会短暂等待上下文以改善中文翻译。

人名、公司名、项目名、缩写可以放到 profiles/custom_terms.txt。需要固定中文译法的术语放到 profiles/terms.yaml，支持 variants、中文目标、category 和 priority。每句话只会注入命中的 top terms。

- source: Kundentabelle
  variants: ["Kunden Tabelle", "customer table"]
  zh: 客户表
  category: data
  priority: high

可以用辅助命令搜索、添加或导入术语，不需要手动改 YAML。

python run.py --glossary-search "Bitte pruefen Sie die Kunden Tabelle." --profile de
python run.py --glossary-add "Kundentabelle" --glossary-zh "客户表" --glossary-variants "Kunden Tabelle,customer table" --glossary-category data --glossary-priority high --glossary-profiles de,de-en
python run.py --glossary-import /absolute/path/to/terms.csv

CSV 导入支持 source、zh 或 target_zh、variants、category、priority、profiles。已有 source 会原地更新。

如果安装了 Silero VAD，默认会自动使用；没有安装时会继续使用内置 energy VAD。

python -m pip install -r requirements-vad.txt
export LMC_VAD_MODE=auto

为了降低第一句话延迟，建议保持 LMC_WARMUP=1。为了避免 partial 抢占正式字幕 CPU，建议保持 LMC_PARTIAL_SKIP_WHEN_ASR_BUSY=1。常见语气词会本地翻译，短句会自动使用更小的 Ollama 输出上限，重复完整句会走缓存，LMC_SHUTDOWN_WAIT_MS 控制退出时等待后台任务的最长时间。

隐私模式关闭时，磁盘翻译缓存会保存在 logs/cache/translation_cache.jsonl。Performance timeline JSONL 会写到 logs/performance/，只记录耗时元信息，不包含逐字稿正文。

如果 Ollama 请求卡住，或者退出时等待太久，可以设置 LMC_OLLAMA_TIMEOUT_SECONDS=20。

Privacy / 隐私

English

Raw audio is not saved by default. Reports contain only transcript text and Chinese translations.

python run.py --mac-live --profile de --privacy

python run.py --doctor stores environment metadata only. It does not record audio or read transcript contents.

Use debug audio only while diagnosing ASR problems. It writes completed speech chunks to logs/debug_audio/.

中文

默认不保存原始音频。报告只包含逐字稿和中文翻译。

python run.py --mac-live --profile de --privacy

python run.py --doctor 只保存环境元信息，不录音，也不读取逐字稿内容。

只有排查 ASR 问题时才建议开启 debug audio，它会把切好的语音片段写入 logs/debug_audio/。
